Entry for the [make.fun competition "One-Liner Laughs"](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41): one funny joke, a single line of at most 200 characters.

`main.ts` writes the joke to `/output/entry.txt`:

> I asked my GPS for the fastest route home and it said, 'Honestly? Therapy.'

Run with Node 22+: `node main.ts`
